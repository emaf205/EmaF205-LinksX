# EMAF205 Links

Minimal link page powered by three files:

```txt
index.php
page.txt
style.txt
```

No database. No admin panel. No build step.

## Quick start

Upload these three files to a PHP-enabled folder:

```txt
index.php
page.txt
style.txt
```

Open the folder in your browser.

## Edit content

Open:

```txt
page.txt
```

Edit:

```txt
SITE_TITLE
SITE_DESCRIPTION
ITEM
TITLE
URL
TARGET
FOOTER_TEXT
```

## Edit style

Open:

```txt
style.txt
```

Optional fields:

```txt
BACKGROUND_COLOR
TEXT_COLOR
FONT
BUTTON_BACKGROUND
BUTTON_TEXT_COLOR
BUTTON_BORDER_COLOR
```

Leave fields empty to use the default minimal style.

## Visual rules

- square buttons
- uppercase button text
- no bold text
- title
- description
- buttons
- footer
